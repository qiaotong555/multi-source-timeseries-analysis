## F 预测分析（已获同意，P3，未立项，预计 3–5 天）

### 定位

预测是**新增能力**，不是把现有解释性结论改写成预测。两者在报告里必须分开标注：
解释性结论回答「发生了什么」，预测结论回答「在给定假设下可能发生什么」。

### 范围

- 单变量与多变量点预测，horizon 可配置（默认 24 步 / 7 天）；
- 预测区间（残差经验分位或 conformal），不用「点估计 + 假装确定」；
- walk-forward 回测：滚动训练、严格按时间切分，禁止未来信息进入特征；
- 基线：naive（最后值）、seasonal naive、移动平均。**必须与 seasonal naive 对比**。

### 硬约束

1. 训练/验证/测试按时间切分，任何特征只用 t 及以前的数据；
2. 泄漏测试：把未来特征打乱后指标不得变好，否则判定实现有泄漏；
3. 模型不 beat seasonal naive 时，报告必须写「未优于基线」，不得包装成成功；
4. 预测结论单独分类（`预测`），并写明 horizon、假设、区间与回测指标；
5. 不做股票交易建议、不做彩票、不宣称因果。

### 验收草案（先写后测）

| 编号 | 标准 |
| --- | --- |
| F1 | 合成数据（已知趋势+季节+噪声）上 MASE < 1（优于 seasonal naive） |
| F2 | 90% 区间的实测覆盖率在 0.85–0.95 |
| F3 | 泄漏测试通过：打乱未来特征后指标不提升 |
| F4 | 回测窗口与切分写入 `result.json`，可复算 |
| F5 | 既有解释性结论与检测阈值不变 |
| F6 | 报告把预测结论与解释性结论分节展示 |

### 不做

- 不做「涨跌预测」「中奖号码」类承诺；
- 不把预测误差包装成确定性结论；
- 不在没有回测的情况下给单点预测。
