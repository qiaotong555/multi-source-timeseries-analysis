### T2.2 改造要点（开工前必读）

目标：实现观察—决策—行动循环，使流程长度由模型决定。

| 项目 | 内容 |
| --- | --- |
| 新增 | `src/mtsa/agent_runtime.py`（已落地） |
| 决策输出 | `{"action": 工具名 或 "finish", "args": {...}, "reason": "..."}` |
| 终止条件 | 模型调 `finish`；步数达上限（默认 8）；无未执行工具且模型未结束；连续两次空转 |
| 接口 | 复用 `mtsa.tools` 的六个工具；准备层与收尾层固定，不进循环 |
| 硬约束 | 数值仍由代码产出；工具失败不得使整次运行崩溃（见 T2.7） |
| 回滚 | `--mode pipeline`（默认值）或 `MTSA_AGENT=off` |

改造范围已界定，不在此范围内的部分不得擅自扩大：

| 层 | 节点 | 是否自主 |
| --- | --- | --- |
| 准备层 | 导入、规模检查、摘要、质量、场景识别、计划、清洗 | 固定 |
| 分析层 | 指标、频域、统计检验、异常、变化点、泄漏检查 | **模型自主** |
| 收尾层 | 图表、报告、证据校验 | 固定 |

## T2.13 token 预算（立项 2026-10-23，已完成）

> 验收记录见 `spec/项目承接已完成.md` 第 22 章。

### 目标

给 Agent 循环加一个**成本上限**：累计 token 达到上限时停止调用模型，并以明确的
终止原因结束。解决「长问题或反复试错时成本无上限，只能事后看账单」的问题。

### 背景

T2.8 起已记录 token（`data.agent.tokens`），但只记录不拦截。实测 13 用例平均
4,152 token/次，最大 7,854；步数上界虽由 `max_steps` 限制，单步 prompt 仍会随
数据列数增长。`max_steps` 不是成本边界。

### 接口

| 项 | 内容 |
| --- | --- |
| 请求字段 | `agent_max_tokens: int = 0`（0 = 不限制，保持既有行为） |
| CLI | `--agent-max-tokens N` |
| 终止原因 | 新增 `token_budget`（不得复用 `model_finished`） |
| `result.json` | `data.agent.budget = {limit, used, remaining, enforced, exhausted, unavailable}` |
| 报告 | `### 3.1 Agent 执行轨迹` 增加「token 预算」行 |

### 语义（必须先定义清楚）

1. **只约束模型调用**：预算检查发生在每次决策之前；工具执行不消耗 token，
   因此超限前的最后一次决策仍会执行完所选工具，结果不丢。
2. **`limit=0` 表示不限制**，`budget.enforced=false`，行为与 T2.12 逐字段一致。
3. **服务端未返回 `usage`**：`budget.unavailable=true`，运行继续并在 `warnings`
   写明「预算未生效」。不估算、不猜测 token——猜测值会变成假账。
4. **`used` 以客户端 `usage_summary().total_tokens` 为准**，不自行按字数折算。

### 验收标准（先写后测）

| 编号 | 标准 | 验证方式 |
| --- | --- | --- |
| A1 | 设限且超限：`terminate_reason == "token_budget"`，`budget.exhausted == true` | 单测：假客户端按调用累加 usage |
| A2 | 不设限：终止原因与 T2.12 一致，`budget.enforced == false` | 单测 + 既有 304 项回归 |
| A3 | `usage` 缺失：`budget.unavailable == true`，运行不中断，`warnings` 有说明 | 单测（FakeClient 无 usage） |
| A4 | 截断后轨迹仍完整、可重放（`trajectory_sha256` 可复算） | 单测 + 一次真实运行 |
| A5 | 成本可解释：`budget.used` 等于服务端 `usage.total_tokens` 累计 | 真实运行对照 `tokens` |
| A6 | 全量测试通过（当前基线 304 项） | `python run_tests.py --timeout 400` |

### 不做的事

- 不做单步 prompt 的 token 预估裁剪（属于 `observation.py` 的职责，已有 6000 预算）；
- 不做美元成本换算（价格随供应商与缓存命中变化，无法离线核实）；
- 不把预算失败包装成普通成功：超限必须能从 `terminate_reason` 看出来。
